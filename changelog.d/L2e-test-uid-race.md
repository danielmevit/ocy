- L2e-test-uid-race: Fixed a flaky Unix single-instance test (macOS CI run 45039345904): `test_uid()` shared one probe file across parallel test threads, so one thread could delete it before another read its metadata, silently falling back to uid 0 and planting a symlink at the wrong fallback dir. Each call now probes its own file (atomic counter + pid) and panics with a clear message instead of falling back to 0; `long_data_dir()` is also unique per call so one test's `remove_dir_all` cleanup can never delete another test's lock file. Test-only change, no production code touched.
