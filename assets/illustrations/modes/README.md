# Mode illustrations (PLACEHOLDER)

Placeholder art: the V10 playful set, regenerated by `gen.py` with V11 dark tokens (light ink on a
deep jade body, so the outline no longer vanishes on the dark card). **The final art is by the owner**
and replaces these files only; no code changes are needed if names, sizes and frame counts match.

## Where it shows
- **Settings header:** the current mode's scene, 160 x 110 logical px (104 x 72 while Customize is
  open), flip-book idle loop (frozen on frame 1 under reduced motion).
- **Preset cards:** the mode glyph, 20 x 20 logical px, next to Gentle / Balanced / Focused.

## Files to replace (all in `svg/`, 40 files)
| File | View box | Count |
| --- | --- | --- |
| `scene-<mode>-<theme>-f<N>.svg` | `0 0 160 110` | 4 modes x 2 themes x 4 frames = 32 |
| `glyph-<mode>-<theme>-f1.svg` | `0 0 40 40` (any square) | 4 modes x 2 themes = 8 |

- `<mode>`: `gentle`, `balanced`, `focused`, `custom` (custom is the "Yours"/Custom mode).
- `<theme>`: `light`, `dark`. Dark art sits on `#212426`; keep its ink light enough to read there.
- `<N>`: `1`..`4`. Frame 1 is the still (reduced motion and first paint).
- Plain SVG that resvg renders (no text, no external images, no scripts).
- Keep the scene aspect 160:110; it is drawn at its own aspect, 160 px wide.

## Timing
`manifest.json` holds each scene's `sequence` (frames in order, looped), `stepMs` and `frozen`.
To change the loop, edit only the manifest, but keep one timing for all four scenes: the header
reads the timing of the mode active when Settings opens and keeps it while the mode is switched. A different **number** of scene frames also needs
`SCENE_FRAMES` in `rust/apps/ocy/ocy-app/src/mode_art.rs`, the `mode_entries!` list there, the
gallery's `mode_svgs!` in `rust/apps/ocy/ocy-ui/tests/support/mod.rs`, and the `* 4` index in
`settings_v2.slint` (`scene-index`).

## Regenerating the placeholder
`python3 -I gen.py svg` (writes all 40 files).
