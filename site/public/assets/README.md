# Site assets

- `screens/{light,dark}/*.png`: headless renders of the real Ocy app (0.2.x), used inside the "The real app" stage.
- `laptop/laptop-{800,1600}.{avif,webp}`: the laptop photo behind the stage. It is an AI-generated image made with
  Magnific on the project owner's account on 2026-11-21. It was edited for Ocy: cropped from the 3072 × 2048 px original to
  2880 × 1920 and exported as AVIF/WebP. The display was generated as a flat grey panel; the app
  screens are composited over it in CSS. The display box on the crop is x 14.722 %, y 6.302 %, w 70.694 %,
  h 62.344 %.
