- Rust: new `damt-build` kit crate — a pure-Rust Windows resource writer (`ResourceBuilder::new().manifest(xml).icon(path).version_info(..).write_coff(out_dir, stem, target)`) that emits a COFF `.rsrc` object with `RT_MANIFEST`, one `RT_ICON` per `.ico` image plus the `RT_GROUP_ICON` directory, and a `VERSIONINFO`; no external resource compiler (`rc.exe`, `llvm-rc`, `mt.exe`, `clang-cl`) is needed, so native and cross builds use one path. Round-trip tests parse the COFF back and assert the resource tree; `ocy-app` now embeds `ocy.ico` (9 sizes) this way and `embed-resource`/`ocy.rc` are gone.
- Rust: `ocy-core`'s `AppDataStore` writes the platform newline (CRLF on Windows, LF elsewhere — matching .NET's `Environment.NewLine`) by default, with `NewlineStyle::Lf`/`Crlf` via `AppDataStore::with_newline` for tests; the byte-identical C# fixtures pin LF explicitly, and new tests cover CRLF output plus reading both CRLF and LF files.
