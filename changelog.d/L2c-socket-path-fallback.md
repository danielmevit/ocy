- L2c-socket-path-fallback: Fixed the Unix single-instance check (all 6 macOS CI test failures): the lock file alone decides first-versus-already-running, so a socket bind failure no longer makes the app refuse to start; a stale socket (even a responsive one) is always replaced while the lock is held; and socket paths longer than `sockaddr_un::sun_path` (104 bytes on macOS, 108 on Linux) fall back to `$XDG_RUNTIME_DIR` or a per-user 0700 `/tmp/<app>-<uid>/` directory with an FNV-1a hashed socket name, computed identically by every instance.
