- Rust (`ocy-core`): the natural-moment hold cap now covers the whole hold, not each kind. When a held start changes kind mid-hold (e.g. a held short break is overtaken by the long-break warning becoming due), the original `due_at` is kept and only the kind switches, so one continuous hold lasts at most `NATURAL_MAX_HOLD` (60 s) from the first moment something became due instead of restarting the cap per kind (worst case about 2 minutes). A start, pause, away or sleep still clears the hold and the next due moment holds afresh. New tests: a short break held 50 s releases the warning within the remaining ~10 s, and continuous typing across a kind change totals exactly 60 s.
- Rust (`ocy-app`): exact hours now read naturally in the tray and tooltip. "1 h 00 min left" becomes "1 h left" (and "2 h left"); "1 h 15 min" is unchanged. Uses the new `time.format.hours` string key (`"{hours} {hoursUnit}"`) added to `en.json`, `de.json`, `mk.json` and `ja.json` (Macedonian plurals come from the existing `time.hours.one/other` unit key). The C#-parity `Strings::time_text` formatter keeps "1 h 00 min" so the C# mirror test stays valid; the C# `tests/Ocy.Desktop.Tests/StringsTests.cs` `TimeText_OneHourOrMore` case `[InlineData(60 * 60, "1 h 00 min")]` still expects the old text and is unaffected (reported to the lead, not changed here).
